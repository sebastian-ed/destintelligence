DESTINTELLIGENCE V5.4 · ACTUALIZACIÓN DESDE V5.3

QUÉ SE CORRIGIÓ
- index.html ahora carga config.js antes de app.js.
- public.html también carga config.js.
- Se agregó recuperación de contraseña desde el login.
- El enlace de recuperación vuelve a la misma URL pública de la aplicación.
- Se agregó detección del evento PASSWORD_RECOVERY y pantalla para elegir una contraseña nueva.
- La contraseña nueva exige al menos 8 caracteres en la interfaz.
- Se agregaron versiones ?v=5.4.0 a los scripts principales para reducir problemas de caché al actualizar GitHub Pages.

PARA ACTUALIZAR TU GITHUB
1. Conservá tus valores reales de SUPABASE_URL y SUPABASE_ANON_KEY.
2. Reemplazá en el repositorio los archivos de esta V5.4.
3. Volvé a colocar tus datos reales en config.js si al reemplazarlo quedaron los valores de ejemplo.
4. Hacé commit y esperá a que GitHub Pages publique la nueva versión.
5. Recargá la web con Ctrl+F5.
